# 插件当前批次下载

## 目标

Chrome 插件完成一次候选人采集并成功导入后，用户可以直接在插件弹窗中把该次采集批次导出为 CSV，并保存到 Chrome 默认的 Downloads 目录。

## 验收要求

- 插件弹窗新增“下载当前批次 CSV”按钮。
- 未产生成功批次时按钮不可用；采集成功后启用。
- 插件保存采集接口返回的批次 ID，下载时必须按该 ID 请求，不能改用“最新批次”。
- 已保存批次必须绑定产生它的本地接口连接；接口地址或 Token 变化后清除旧批次，禁止跨数据库复用同号批次。
- 本地接口仅在 Token 验证通过后返回指定批次的 UTF-8 CSV。
- 下载使用 Chrome 默认 Downloads 目录且不弹出另存为窗口。
- 批次不存在时不产生空文件，并向用户显示明确错误。
