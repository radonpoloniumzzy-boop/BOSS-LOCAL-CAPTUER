# 下一步动作及提醒

## 目标

把候选人岗位关系和招聘任务需要继续推进的事项集中为可执行待办，明确做什么、谁负责、什么时候完成，并在应用内提示今日与逾期事项。

## 本次范围

- 待办可关联一个候选人岗位关系或一个招聘任务；
- 可记录动作类型、标题、负责人、截止时间、优先级和备注；
- 支持待处理、已完成、已取消状态，完成后记录仍保留；
- 提供全部待办、今日、逾期、未来七天和已完成视图；
- 汇总待处理、今日、逾期、未来七天和今日已完成数量；
- 可从候选人页面或招聘任务页面创建预填待办；
- 可从待办页面返回对应候选人或招聘任务；
- 待办状态与候选人招聘进度、招聘任务执行状态相互独立。

## 首版动作类型

- 待触达；
- 待跟进；
- 待补资料；
- 待复核；
- 待约面；
- 待收面试反馈；
- Offer 跟进；
- 暂缓后复查；
- 其他。

## 暂不包含

- 自动联系候选人或自动发送平台消息；
- Windows 系统级弹窗、短信、邮件或第三方日历提醒；
- 多人权限、任务分派审批和冲突合并；
- 根据待办完成自动改写招聘状态；
- 自动生成无限连续待办。
