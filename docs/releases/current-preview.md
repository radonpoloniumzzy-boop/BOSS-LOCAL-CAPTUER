# 当前预览版本说明

## 组件版本来源

- 核心工作台版本：`core/version.py`
  - 当前值：`0.3.0-web-phase-2c`
- Chrome 插件版本：`extension/manifest.json`

这些版本属于不同组件，不自动合并成一个统一产品号。

## 当前稳定可用功能

- 网页工作台启动与首次设置
- 本地人才库目录确认
- Chrome 插件连接码配对
- 招聘平台页面采集
- 候选人列表查看
- 最近采集批次查看
- 批次 Markdown 导出
- 网页端与旧桌面端的人才库互斥保护

## 当前未完成功能

以下内容仍属于后续阶段，不应在当前预览中承诺为已完成：

- 岗位中心正式工作流
- 人才 Mapping
- AI 初筛
- 人工复核闭环
- 简历分类归档
- 沟通记录与招聘推进全链路

## 已知边界

- Chrome 插件仍是招聘平台页面采集入口。
- 网页工作台是当前默认主入口。
- 旧桌面端只作为兼容入口保留。
- 程序不会在数据库缺失时创建空库替代旧库。
- 网页端和旧桌面端不能同时占用同一人才库。

## 关于旧的“紧凑型分屏工作台”Issue

旧 Issue 关注的是桌面端在半屏与紧凑布局下的可用性。

现在主路线已经切到网页工作台，所以它没有完全失效，但优先级和适用面已经被网页路线明显替代：

- 如果目标是当前正式试用版本的日常使用体验，应该优先推进网页工作台；
- 如果目标仍是维护旧桌面兼容入口，那条 Issue 仍有参考价值。
