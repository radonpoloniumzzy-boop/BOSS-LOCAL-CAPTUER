# 备份与恢复

这份文档只讲当前版本最需要守住的几件事：人才库在哪、什么时候备份、出问题时不要怎么做。

## 重要位置

### bootstrap

默认位置：

```text
%LOCALAPPDATA%\RecruitingTalentWorkbench\bootstrap.json
```

它记录当前网页工作台指向哪个数据目录、使用哪个网页端口。

### 人才库目录

真正的人才库目录由首次设置时确认。

目录里最关键的文件通常包括：

- `boss_local_tool.db`

如果你不确定当前数据目录，可以先检查 `bootstrap.json`。

## 什么时候备份

请在以下前提下备份：

- 网页工作台已关闭；
- 旧桌面端已关闭；
- 没有任何实例占用当前人才库。

## 如何备份

1. 先确认程序全部关闭。
2. 复制整个人才库目录到另一个安全位置。
3. 同时备份 `%LOCALAPPDATA%\RecruitingTalentWorkbench\bootstrap.json`。

## 故障处理原则

### 数据库文件缺失

- 不要创建新的空库覆盖旧位置。
- 先检查：
  - D 盘是否挂载；
  - 移动盘是否连接；
  - 文件是否被改名或移动。
- 找回原 `boss_local_tool.db` 后再启动。

### 数据库损坏

- 先保留故障文件副本；
- 不要直接覆盖；
- 从最近可用备份恢复。

### 数据库被占用

- 先关闭旧桌面端；
- 再关闭其他网页工作台实例；
- 确认只剩当前这一次启动。

### 移动盘未连接

如果你的数据目录在移动盘：

- 先连接原盘；
- 确认盘符未变化；
- 再重启网页工作台。

## 禁止事项

- 不要用新空库替换旧库；
- 不要把源码目录里的 `data/` 当成临时缓存随便删；
- 不要在程序仍运行时直接拷贝活动数据库当作正式备份；
- 不要先覆盖再判断故障原因。

## 恢复前先做的事

先保留：

- 故障数据库副本；
- 当前 `bootstrap.json`；
- 本地日志。

这样就算恢复失败，也还有回退和排查空间。
