# M2.1 客户端试用候选版说明

这份说明用于项目经理组织人工试用。当前候选版覆盖岗位、招聘任务、网页采集、外部评级、关键词标记和任务进度查看；不包含 AI 初筛、自动沟通、联系方式采集、简历附件归档或后续 Mapping 流程。

## 试用前准备

1. 关闭旧的网页工作台窗口和旧桌面端采集程序，避免同时占用人才库。
2. 如首次在本机使用，先双击 `setup_web_workbench.cmd` 完成初始化。
3. 双击 `launch_web_workbench.cmd` 启动网页工作台。正常情况下会出现可见启动窗口，并自动打开默认网页地址 `http://127.0.0.1:17864`。
4. 在 Chrome 扩展管理页重新加载本项目的 `extension` 目录，确保插件使用当前候选版代码。
5. 在网页工作台“设置”页复制一次性连接码，打开插件后粘贴并点击“连接并记住”。

## 最小试用数据建议

为避免大量真实数据变化，建议只准备一个试用岗位和一个试用招聘任务：

1. 在“岗位”页新建一个试用岗位，填写岗位名称和必要描述。
2. 在该岗位下创建一个招聘任务，并启动任务。
3. 在任务卡片中点击“查看进度”，确认下一步提示清楚。
4. 点击“设为插件当前任务”，插件顶部应显示当前任务信息。
5. 打开 BOSS 推荐页，只采集当前已加载的少量候选人。

上述“新建岗位”“创建任务”“启动任务”“采集候选人”“导入外部评级”“保存关键词规则”都会写入当前连接的人才库。只查看候选人、批次、快照和导出 Markdown 不会改写候选人主档。

## 试用主流程

1. **岗位与任务**
   - 入口：“岗位”页。
   - 成功状态：任务卡片显示“执行中”，任务进度抽屉显示任务摘要、下一步、最近批次、候选人和批次入口。

2. **插件当前任务**
   - 入口：任务进度抽屉里的“设为插件当前任务”。
   - 成功状态：网页任务卡片出现“插件当前任务”；插件顶部显示该任务和岗位。

3. **候选人采集**
   - 入口：插件默认面板的“采集当前已加载”或“自动滚动采集”。
   - 成功状态：插件显示网页批次号；网页“最近批次”和任务进度抽屉能看到新批次。

4. **候选人查看**
   - 入口：“候选人”页，或任务进度抽屉的“查看本任务候选人”。
   - 成功状态：列表可搜索、筛选、排序；详情抽屉展示基础信息、原始快照和来源出现历史。

5. **批次查看与导出**
   - 入口：“最近批次”页，或任务进度抽屉的“查看本任务批次”。
   - 成功状态：批次详情展示不可变快照；“导出 Markdown”可下载该批次内容。

6. **外部评级导入**
   - 入口：执行中任务卡片或任务进度抽屉的“导入外部评级”。
   - 最简单输入示例：

   ```text
   候选人,当前评级,最值得看的方向,判断
   测试甲,SSR,高频策略,重点看研究深度
   测试乙,SR,数据工程,工程能力较稳
   ```

   - 成功状态：网页候选人、候选人详情、批次详情和任务进度中显示 `1UR`、`1SSR`、`1SR`、`1R`、`1N`。

7. **关键词规则**
   - 入口：执行中任务卡片的“关键词筛选规则”。
   - 四组输入：必须关键词、加分关键词、风险关键词、关注关键词。
   - 成功状态：BOSS 页面候选人卡片出现关键词命中摘要和高亮；筛选条可切换全部、有必须、有加分、有风险、未命中。

## 安全恢复

- 如果插件显示未连接，回到网页“设置”页重新复制连接码并配对。
- 如果任务暂停、取消或岗位关闭，插件当前任务会失效；重新启动或选择一个执行中的任务后再设置。
- 如果关键词或评级标记看起来不对，刷新招聘平台页面或在插件中重新打开网页工作台状态即可清理旧标记。
- 结束试用时，不需要删除历史数据。可以暂停或完成试用任务，并在插件中清除当前任务或重新配对到其他工作台。

## 边界

当前候选版不会执行 AI 初筛，不会自动沟通，不会采集联系方式，不会下载或归档简历附件。旧桌面兼容入口仍保留，但不是本轮网页试用的默认入口。
