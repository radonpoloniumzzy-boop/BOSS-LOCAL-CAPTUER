# 网页工作台快速开始

这份说明只覆盖当前已经稳定可试用的流程：

启动网页工作台
→ 配对 Chrome 插件
→ 采集候选人
→ 网页查看候选人和批次
→ 导出批次 Markdown

## 第一次安装

1. 安装官方 CPython 3.12。
2. 获取当前 `main` 分支源码。
3. 双击 `setup_web_workbench.cmd`。
4. 看到“初始化完成，请双击 launch_web_workbench.cmd 启动网页工作台。”后，再双击 `launch_web_workbench.cmd`。

## 日常启动

1. 双击 `launch_web_workbench.cmd`。
2. 等待启动窗口完成环境、端口和人才库检查。
3. 浏览器会自动打开网页工作台。

如果启动器提示缺少运行环境，先回到 `setup_web_workbench.cmd`。

## 第一次确认人才库

首次打开网页工作台时，会先确认数据目录。

建议使用：

- 独立、可写、长期保留的本地文件夹；
- 不与项目源码目录混放；
- 不使用随时可能断开的移动盘，除非你明确知道备份和恢复流程。

## 加载 Chrome 插件

1. 打开 `chrome://extensions`
2. 打开“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择项目中的：

```text
extension
```

## 配对插件

1. 在网页工作台“设置”页复制一次性连接码。
2. 打开插件弹窗并粘贴连接码。
3. 配对成功后，插件会自动记住当前网页工作台连接。

网页模式下不需要手工填写 API 地址或 Token。

## 采集与查看

你现在可以：

- 采集当前已加载内容；
- 自动滚动采集；
- 回到网页查看候选人列表；
- 查看最近采集批次；
- 导出某个批次的 Markdown。

## 常见错误最短恢复办法

### 提示缺少运行环境

先运行：

```text
setup_web_workbench.cmd
```

### 提示旧版网页工作台仍在运行

先关闭旧实例，再点“重新检查”。

### 提示桌面端正在使用人才库

关闭旧桌面端后，再重新启动网页工作台。

### 数据库文件缺失或损坏

不要创建新空库覆盖旧库。先保留故障文件副本，再按备份与恢复说明处理。

### 插件没有连上

回到网页“设置”重新复制连接码，再在插件里重新配对。
