# 本地网页迁移期架构

阶段 1 采用 FastAPI + Uvicorn 提供仅绑定 `127.0.0.1` 的本地后台，采用 React + TypeScript + Vite 构建浏览器界面，并由 Python 服务直接提供构建后的静态文件。这样可以逐步迁移界面，同时保留 Python 业务服务、SQLite 数据和离线运行能力。

迁移期间，网页程序与 PySide 桌面程序共用用户确认的数据目录和数据库，但不能同时运行。两端根据数据库绝对路径获取同一应用锁；这是为了避免两个进程在迁移期并发写入同一 SQLite 数据库。异常进程退出后由操作系统回收锁。

浏览器工作台暂用 `127.0.0.1:17864`，现有 Chrome 插件接口继续由桌面端在 `127.0.0.1:17863` 提供。阶段 1 不让网页后台冒充插件服务，也不把插件 Token 暴露给网页 JavaScript。端口合并推迟到插件迁移边界被单独设计和验证之后。
